One pickup line, spoken by a vending machine to a passing human — 110 characters, one breath, punch at the end:

> I drop snacks for anyone with a coin, but if you smile at me again, I'll jam on purpose just to keep you here.

`main.py` (Python 3.13, no dependencies, no network) writes the line verbatim to `entry.txt` in the make.fun output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline. It validates the line first (1–200 characters, not blank) and reads the file back to confirm it matches.
